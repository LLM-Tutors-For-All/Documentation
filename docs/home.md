## Making LLM tutors easier to understand

There is no single best way to deploy an LLM tutor. The right approach depends
on where learners are, how the tutor performs, and what it costs to operate.
This project documents deployment patterns and compares them using practical,
repeatable benchmarks.

### What we explore

- Tutor experiences on platforms such as Discord and Slack
- Performance across different services and deployment approaches
- Cost and operational tradeoffs for each option
